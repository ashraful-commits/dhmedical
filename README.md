## 🌟 প্রকল্প পরিচিতি (Project Overview)

**D H Medical Support** হলো একটি সমন্বিত সেন্ট্রাল মেডিকেল সাপোর্ট এবং ইমার্জেন্সি কোঅর্ডিনেশন প্ল্যাটফর্ম। বিদেশে কর্মরত প্রবাসী ভাই-বোন এবং দেশের প্রত্যন্ত অঞ্চলের পরিবারের জন্য জরুরি চিকিৎসার মুহূর্তে অ্যাম্বুলেন্স প্রেরণ, বিশেষজ্ঞ ডাক্তারের অ্যাপয়েন্টমেন্ট, হাসপাতালের আইসিইউ/বেড বুকিং এবং ২৪/৭ তত্ত্বাবধান নিশ্চিত করাই এই প্ল্যাটফর্মের মূল লক্ষ্য।

DocTime ও Praava Health-এর আদলে আধুনিক ইউজার ইন্টারফেস এবং গ্রামীণ ও শহর উভয় অঞ্চলের মানুষের জন্য সহজ বাংলা ইন্টারফেসে পুরো সিস্টেমটি তৈরি করা হয়েছে।

## 🚀 মূল বৈশিষ্ট্যসমূহ (Key System Features)

### ১. জরুরি অ্যাম্বুলেন্স বুকিং ও ডিসপ্যাচ
* **অ্যাম্বুলেন্সের ধরন:** সাধারণ (Non-AC), সাশ্রয়ী এসি (AC), অক্সিজেন সাপোর্ট (Oxygen), আইসিইউ (ICU), নবজাতক ভেন্টিলেটর (NICU), কার্ডিয়াক লাইফ সাপোর্ট (Cardiac), এবং দূরপাল্লার রোগী পরিবহন (Long Distance)।
* **লাইভ জিপিএস লোকেশন ট্যাগিং:** ব্রাউজারের ফ্রি Geolocation API ব্যবহার করে এক ক্লিকে রোগীর বর্তমান অবস্থান ও ল্যাট-লং ট্যাগ করা যায়।
* **সম্ভাব্য ভাড়া ক্যালকুলেটর:** অ্যাম্বুলেন্সের ধরন অনুযায়ী শুরুতেই ন্যূনতম আনুমানিক ভাড়া ও আগমনের সম্ভাব্য সময় (ETA: ১৫-২৫ মিনিট) প্রদর্শিত হয়।
* **রোগীর অবস্থা ও সঙ্গী সংখ্যা:** রোগীর গুরুতর অবস্থা (Emergency/Stable/Critical) এবং সাথে কতজন এটেনডেন্ট যাবেন তা বুকিংয়ে অন্তর্ভুক্ত।
* **ইউনিক বুকিং আইডি:** সাবমিট করার সাথে সাথে `DH-AMB-YYYYMMDD-XXXX` ফরম্যাটে বুকিং আইডি তৈরি হয় এবং সরাসরি ট্র্যাকিং লিঙ্ক পাওয়া যায়।

### ২. পাবলিক লাইভ বুকিং ট্র্যাকার (`/track`)
* রোগী বা স্বজন যে কেউ বুকিং আইডি অথবা মোবাইল নম্বর দিয়ে তাৎক্ষণিক লাইভ স্ট্যাটাস দেখতে পারেন।
* **৬-ধাপের লাইভ টাইমলাইন:**
  1. `requested` (অনুরোধ গ্রহণ হয়েছে)
  2. `confirmed` (অ্যাম্বুলেন্স নিশ্চিত হয়েছে)
  3. `driver_assigned` (চালক নিযুক্ত হয়েছে)
  4. `on_the_way` (চালক রওনা হয়েছেন)
  5. `picked_up` (রোগী গাড়িতে উঠেছেন)
  6. `completed` (যাত্রা সম্পন্ন হয়েছে)
* **চালকের বিবরণ কার্ড:** চালকের নাম, সরাসরি মোবাইল কল বাটন, গাড়ির লাইসেন্স প্লেট ও অ্যাম্বুলেন্স মডেল প্রদর্শিত হয়।
* **১-ক্লিক ইমার্জেন্সি হটলাইন ও হোয়াটসঅ্যাপ বাটন:** সরাসরি কন্ট্রোল রুমের সাথে যুক্ত হওয়ার দ্রুত ব্যবস্থা।

### ৩. ড্রাইভার ও পার্টনার রেজিস্ট্রেশন (ক্যামেরা ও এনআইডি)
* **ডুয়াল ফটো আপলোড অপশন:** 
  - 📷 **সরাসরি ক্যামেরা অপশন (`Take Photo`):** মোবাইল বা ট্যাবের ব্যাক ক্যামেরা খুলে এনআইডি বা গাড়ির ছবি তোলা যায়।
  - 📁 **গ্যালারি অপশন (`Choose from Gallery`):** ফাইল ম্যানেজার থেকে ছবি নির্বাচন করা যায়।
* **এনআইডি ভেরিফিকেশন:** এনআইডির সামনের পাশ (`NID Front`) এবং পেছনের পাশ (`NID Back`) আলাদাভাবে ক্লাউডিনারি সিকিউর মিডিয়া ড্রাইভে আপলোড হয়।
* ড্রাইভিং লাইসেন্স ও গাড়ির রুট পারমিট সংগ্রহ ও অ্যাডমিন কর্তৃক ভেরিফিকেশন ব্যবস্থা।

### ৪. পূর্ণাঙ্গ হাসপাতাল ডিরেক্টরি (বেড সংখ্যা ও ফ্লোর গাইড)
* **জেলা ও এলাকা ভিত্তিক ফিল্টার:** ঢাকা, চট্টগ্রাম, সিলেট, রাজশাহী, খুলনা, বরিশাল, রংপুর, ময়মনসিংহ, কুমিল্লাসহ সকল জেলার ফিল্টারিং।
* **ভেরিফাইড ও ইমার্জেন্সি ব্যাজ:** ২৪/৭ ইমার্জেন্সি এবং সরকারি/বেসরকারি ভেরিফাইড স্ট্যাটাস।
* **মোট বেড সংখ্যা (Bed Capacity):** হাসপাতালে মোট কত বেড (যেমন: ৭৫০+ শয্যা, ৫০০+ শয্যা) তা সরাসরি প্রদর্শিত।
* **তলা ভিত্তিক রুম ডিরেক্টরি (Floor-by-Floor Guide):**
  - নিচতলা / ১ম তলা: ইমার্জেন্সি, ট্রায়াজ, টিকিট কাউন্টার ও ফার্মেসি
  - ২য় তলা: আইসিইউ (ICU), সিসিইউ (CCU), ক্যাথল্যাব
  - ৩য় তলা: ওটি কমপ্লেক্স ও পোস্ট-অপারেটিভ কেয়ার
  - ৪র্থ তলা: প্যাথলজি ল্যাব, আল্ট্রাসাউন্ড, এক্স-রে ও সিটি স্ক্যান
  - ৫-৭ম তলা: জেনারেল ওয়ার্ড ও কেবিন
* **১০০% ফ্রি গুগল ম্যাপ ডিরেকশন:** কোনো পেইড ম্যাপস এপিআই ছাড়া সরাসরি গুগল ম্যাপস ন্যাভিগেশন লিংক।

### ৫. বিশেষজ্ঞ ডাক্তার সিরিয়াল ও অ্যাপয়েন্টমেন্ট
* ডিপার্টমেন্ট অনুযায়ী ফিল্টারিং (নিউরো মেডিসিন, হৃদরোগ, অর্থোপেডিক, শিশু রোগ, গাইনি, সার্জারি, চক্ষু ইত্যাদি)।
* ডাক্তারদের ডিগ্রি, বিএমডিসি রেজিস্ট্রেশন, চেম্বার, সময় ও ভিজিট ফি স্পষ্ট প্রদর্শন।
* সিরিয়াল বুকিংয়ে স্বয়ংক্রিয় `DH-APT-YYYYMMDD-XXXX` কনফার্মেশন কোড।

### ৬. প্রবাসী পরিবার কেয়ার (DH Family Care)
* প্রবাস থেকে পরিবারের স্বাস্থ্য সুরক্ষায় বিশেষ মেম্বারশিপ প্ল্যান (মৌলিক, সিলভার, প্রবাস প্রিমিয়াম)।
* ২৪/৭ কেয়ার ম্যানেজার, জরুরি ওষুধ ও ল্যাব টেস্টের সমন্বয়, স্বাস্থ্য বীমা সহায়তা।

### ৭. সুরক্ষিত অ্যাডমিন ড্যাশবোর্ড ও কন্ট্রোল সেন্টার (`/admin`)
* **নিরাপদ সার্ভার-সাইড লগইন (`/api/auth/login`):**
  - কোনো ডিফল্ট পাসওয়ার্ড বা অ্যাডমিন কী ফ্রন্টএন্ডে উন্মুক্ত নেই।
  - ব্রুট-ফোর্স রোধে **IP Rate Limiting** (১৫ মিনিটে সর্বোচ্চ ৫ বার ভুল পাসওয়ার্ডের সুযোগ)।
  - ক্রিপ্টোগ্রাফিক HMAC সিকিউর সেশন টোকেন।
* **ড্রাইভার অ্যাসাইনমেন্ট মোডাল:** এক ক্লিকে বুকিংয়ের জন্য ড্রাইভারের নাম, ফোন ও গাড়ির নম্বর যুক্ত করা।
* **লাইভ স্ট্যাটাস পরিবর্তন:** টাইমলাইন আপডেট করার সাথে সাথে গ্রাহকের ট্র্যাকিং পেজে তাৎক্ষণিক প্রতিফলিত হয়।
* **ক্যাটালগ ম্যানেজমেন্ট:** নতুন ডাক্তার, নতুন হাসপাতাল, বেড সংখ্যা ও ফ্লোর ডিরেক্টরি সংযোজন, সংশোধন ও মুছে ফেলা।
* **১-ক্লিক ডেমো সিডার (`Seed 14+ Doctors & 8+ Hospitals`):** এক ক্লিকে ডাটাবেজে বাস্তবসম্মত ডেমো ডাটা পপুলেট করার সুবিধা।

### ৮. স্বয়ংক্রিয় হিসাব ও আয়-ব্যয় খতিয়ান (Financial Ledger)
* প্রতিটি অ্যাম্বুলেন্স ট্রিপ সম্পন্ন (`completed`) হলে স্বয়ংক্রিয়ভাবে খতিয়ানে এন্ট্রি হয়:
  - মোট ভাড়া (Total Fare)
  - পার্টনার শেয়ার: ৮০% (ড্রাইভার/মালিকের প্রাপ্য)
  - প্ল্যাটফর্ম কমিশন: ২০% (D H Medical Support আয়)
* অ্যাডমিন ড্যাশবোর্ডে মোট আদায়কৃত অর্থ, পার্টনারদের প্রদেয় এবং নেট লাভ সরাসরি প্রদর্শিত।

### ৯. অডিট ও অ্যাক্টিভিটি লগ (Security Activity Logs)
* প্রতিটি সংবেদনশীল কাজের (যেমন: অ্যাডমিন লগইন, স্ট্যাটাস পরিবর্তন, ড্রাইভার অ্যাসাইন, ডাটাবেজ সিডিং) অপরিবর্তনীয় অডিট ট্রেইল সংগৃহীত হয়।

## 🗄️ ডাটাবেজ স্কিমা ও মডেল (Database Schemas)

সিস্টেমে ব্যবহৃত প্রধান কালেকশনসমূহ:

1. **`ambulance`**: রোগীর নাম, মোবাইল, বর্তমান ঠিকানা, জিপিএস কোঅর্ডিনেট, গন্তব্য, অ্যাম্বুলেন্স ধরন, জরুরি অবস্থা, সঙ্গী সংখ্যা, সম্ভাব্য ভাড়া, স্ট্যাটাস টাইমলাইন, অ্যাসাইন করা ড্রাইভারের তথ্য।
2. **`appointments`**: রোগীর নাম, মোবাইল, বয়স, পছন্দের ডাক্তার, হাসপাতাল, তারিখ, বিভাগ, বুকিং আইডি, স্ট্যাটাস।
3. **`partners`**: চালক/মালিকের নাম, ফোন, গাড়ির ধরন, লাইসেন্স নম্বর, এনআইডি ফ্রন্ট ও ব্যাক ফটো, গাড়ির ফটো, স্ট্যাটাস।
4. **`memberships`**: প্রবাসী সদস্যের নাম, প্রবাসের দেশ, দেশে পরিবারের যোগাযোগের ঠিকানা, মেম্বারশিপ প্ল্যান।
5. **`hospitals`**: হাসপাতালের নাম, জেলা, ঠিকানা, ফোন, বেড সংখ্যা (`bedCount`), ফ্লোর ডিরেক্টরি (`floors`), ইমার্জেন্সি হটলাইন, লোগো।
6. **`doctors`**: ডাক্তারের নাম, বিশেষজ্ঞ বিভাগ, ডিগ্রি, বর্তমান হাসপাতাল, ভিজিট ফি, সময়সূচি, ছবি।
7. **`feedback`**: রোগীর নাম, রেটিং (১-৫ তারা), মন্তব্য, স্ট্যাটাস।
8. **`accounts`**: ট্রিপ রেফারেন্স আইডি, মোট ভাড়া, পার্টনার পে-আউট (৮০%), ডিএইচ প্ল্যাটফর্ম কমিশন (২০%), পেমেন্ট মেথড ও স্ট্যাটাস।
9. **`activity_logs`**: ইভেন্ট অ্যাকশন, অ্যাক্টর (ইউজার/অ্যাডমিন), আইপি অ্যাড্রেস, বিবরণ ও টাইমস্ট্যাম্প।

## ⚙️ এনভায়রনমেন্ট ও সেটআপ গাইড (Environment & Local Setup)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/ashraful-commits/dhmedical.git
cd dhmedical
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভেরিয়েবল সেট করুন (`.env.local`)
প্রজেক্টের রুট ডিরেক্টরিতে `.env.local` ফাইল তৈরি করুন:

```env
# MongoDB Atlas কানেকশন স্ট্রিং
MONGODB_URI=mongodb+srv://<username>:<password>@mern.sho5qfe.mongodb.net/dh?retryWrites=true&w=majority

# Cloudinary মিডিয়া আপলোড ক্রেডেনশিয়াল
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# অ্যাডমিন প্যানেল মাস্টার সিক্রেট কি
ADMIN_KEY=dhadmin123
```

> **টিপস (Windows ইউজারদের জন্য):** MongoDB Atlas SRV ডোমেইন সহজে রেজলভ করার জন্য `lib/mongodb.js`-এ স্বয়ংক্রিয়ভাবে Google DNS (`8.8.8.8`) কনফিগার করা রয়েছে।

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

## 🚀 ভার্সেল ডিপ্লয়মেন্ট গাইড (Vercel Production Deployment)

প্রজেক্টটি Vercel-এর সাথে শতভাগ সামঞ্জস্যপূর্ণ।

1. আপনার গিটহাব অ্যাকাউন্টে কোড পুশ করুন:
   ```bash
   git push origin main
   ```
2. [Vercel Dashboard](https://vercel.com)-এ যান এবং রিপোজিটরিটি Import করুন।
3. **Environment Variables** সেকশনে এই ৪টি ভেরিয়েবল যুক্ত করুন:
   - `MONGODB_URI`
   - `CLOUDINARY_CLOUD_NAME`
   - `CLOUDINARY_API_KEY`
   - `CLOUDINARY_API_SECRET`
   - `ADMIN_KEY`
4. **Deploy** বাটনে ক্লিক করুন।
5. **গুরুত্বপূর্ণ:** MongoDB Atlas-এর **Network Access** সেটিংসে গিয়ে IP Whitelist `0.0.0.0/0` (Allow Access from Anywhere) নিশ্চিত করুন, যাতে ভার্সেলের সার্ভারলেস ফাংশন ডাটাবেজে যুক্ত হতে পারে।
